# SmartCount – People Counting & Occupancy Analytics

## Overview
SmartCount is a Python-based people counting and
occupancy analytics system designed to monitor
individuals entering and leaving a designated space.

The system records movement events, timestamps,
and occupancy levels to support data-driven
decision-making.

## Objectives
- Automate people counting.
- Monitor room occupancy.
- Record entry and exit timestamps.
- Generate statistical insights.
- Explore industrial and mining applications.

## Key Features
- Entry and exit tracking
- Occupancy calculation
- Timestamp recording
- Traffic pattern analysis
- Statistical reporting
